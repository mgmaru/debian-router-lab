# Routing

## デフォルトゲートウェイ

### 一言でいうと

**「自分のネットワークの外にある宛先は、全部ここに渡す」という窓口のアドレス**です。

### なぜ必要か

クライアント VM に `10.0.0.10/24` を設定すると、VM は次のように判断して送信します。

| 宛先 | VM の判断 |
|---|---|
| `10.0.0.1`（範囲内） | 同じネットワークにいるので、**直接送る** |
| `8.8.8.8`（範囲外） | どこにいるか、どう行けばいいか**わからない** |

範囲外の宛先について、VM 自身は何も知りません。そこで「わからない宛先は `10.0.0.1` に渡す」と決めておきます。`10.0.0.1` はルーター VM で、ルーター VM は外側（ens33）にもつながっているので、そこから先へ運べます。

（「範囲内」「範囲外」の考え方は [interface.md](interface.md#ip-アドレスと-24) を参照）

### たとえ

会社の書類のやりとりで考えると：

- **同じフロアの人宛て** → 自分で直接持っていく（同じネットワーク内の通信）
- **社外宛て** → 相手の住所までの道順を自分で調べたりせず、**総務の発送窓口に渡す**。そこから先は窓口に任せる

この「発送窓口」がデフォルトゲートウェイです。各社員（各端末）は、社外の道順を知らなくても「窓口の場所」だけ知っていればいい、というのがポイントです。

### 設定しないとどうなるか

範囲外の宛先に送ろうとした瞬間に `Network is unreachable`（届け方がわからない）というエラーになります。**送り出すことすらできません。**

### コマンドでいうと

設定ファイルの `gateway 10.0.0.1` は、次のコマンドを起動時に実行するのと同じです。

```bash
sudo ip route add default via 10.0.0.1
```

`default` は「ほかに当てはまる経路がない、すべての宛先」という意味です。`ip route` を実行すると、次のような行で確認できます。

```
default via 10.0.0.1 dev ens33
```

### ルーター VM に `gateway` を書かなかった理由

ルーター VM の設定ファイルには、ens33 にも ens37 にも `gateway` を書いていません。理由は 2 つあります。

**① ens33（外側）は、DHCP がデフォルトゲートウェイを配ってくれるから**

ルーター VM の ens33 は `iface ens33 inet dhcp`、つまり DHCP で設定をもらう NIC です。DHCP は IP アドレスだけでなく、**デフォルトゲートウェイも一緒に配ります**（詳しくは [dhcp.md](dhcp.md)）。そのため、自分で `gateway` を書かなくても、VMware の NAT（通常は `192.168.22.2`）がデフォルトゲートウェイとして自動で設定されています。

ルーター VM で確認できます。

```bash
ip route
```

```
default via 192.168.22.2 dev ens33 ...
```

> ⚠️ 「ルーター VM にはデフォルトゲートウェイが**不要**」なのではありません。ルーター VM も外へ出るには出口が必要です。「**DHCP が入れてくれるので、自分で書かなくても手に入る**」というのが正しい理解です。

**② ens37（内側）に書くと、出口が 2 つになるから**

デフォルトゲートウェイは基本的に 1 台に 1 つです。ens33 側にすでに出口があるのに、内側の ens37 にも書くと「外への出口」が 2 つになって経路が混乱します。

### 2 台の比較

| VM | デフォルトゲートウェイ | どうやって設定されたか |
|---|---|---|
| ルーター VM | `192.168.22.2`（VMware の NAT） | ens33 の **DHCP で自動** |
| クライアント VM | `10.0.0.1`（ルーター VM） | 設定ファイルに `gateway` で**手で書いた** |

クライアント VM は静的 IP にしたので DHCP から何も受け取れません。そのため、DHCP なら自動で入ってくる分（IP アドレスとゲートウェイ）を自分で書く必要があった、ということです。

デフォルトゲートウェイの効果を確かめる実験は [labs/01-network-interface](../../labs/01-network-interface/README.md) を参照。
