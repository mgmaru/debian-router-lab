# エディタ（vi / nano）

## vi のキー操作がおかしいのは「キー配列の違い」ではない

SSH では、**キー入力は手元（Mac）のターミナルが文字に変換してから送ります**。そのため、接続先（Debian）や VM ホスト（Windows）のキー配列設定は関係しません。

よくある原因は次の 2 つです。

### 原因 1：Debian 標準の vi が最小版（vim-tiny）

Debian に最初から入っている `vi` は機能を削った **vim-tiny** で、昔の vi と同じ動きをします。

- 挿入モードで矢印キーを押すと `A` `B` `C` `D` が入力される
- Backspace で、入力し始めた位置より前の文字が消せない

これは**仕様**です。対処：

```bash
sudo apt install vim     # 普通の vim を入れれば直る
```

### 原因 2：Mac の入力モードが日本語

日本語入力のままだと `i` や `:wq` が全角で送られ、コマンドとして効きません。**vi を使うときは英数入力**にします。

## nano の使い方

nano は **モードがなく、開いたらそのまま文字を打てる** エディタです。Debian には最初から入っています。画面下に操作一覧が出ているので、それを見ながら使えます。

```bash
sudo nano /etc/network/interfaces
```

### 基本の流れ

1. 矢印キーでカーソルを動かし、そのまま入力・Backspace で削除
2. `Ctrl+O` → Enter で保存（ファイル名を聞かれるので、そのまま Enter）
3. `Ctrl+X` で終了

保存せずに `Ctrl+X` を押すと「保存しますか？」と聞かれるので、`Y`（保存）か `N`（破棄）を押します。

### 画面下の記号の読み方

| 記号 | 意味 | Mac での押し方 |
|---|---|---|
| `^` | Ctrl キー（`^X` = `Ctrl+X`） | **Control** キー（Command ではない） |
| `M-` | Meta キー（`M-U` など） | `Esc` を押して離してから次のキー |

### よく使う操作

| 操作 | キー |
|---|---|
| 保存 | `Ctrl+O` → Enter |
| 終了 | `Ctrl+X` |
| 検索 | `Ctrl+W` → 文字列 → Enter |
| 1 行切り取り | `Ctrl+K` |
| 貼り付け（切り取った行） | `Ctrl+U` |
| 元に戻す | `Esc` → `U` |
| ページ送り | `Ctrl+V`（次）/ `Ctrl+Y`（前） |
| ヘルプ | `Ctrl+G` |

Mac でコピーしたテキストは、普段どおり `Command+V` でターミナルに貼り付けられます。
