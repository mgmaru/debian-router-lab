# プライベートIPとグローバルIP：知られると危ないのはどちらか

調査日：2026-10-08

関連：

- [WANの入口は攻撃者の標的になるのか](2026-10-08-is-wan-entrance-a-target.md)
- [IPアドレスを知られると侵入されるのか（Tailscale・VMのIP）](2026-10-08-is-knowing-ip-address-dangerous.md)

## 疑問

> **質問4**：プライベートIPが知られたとしても、侵入にはならないという認識で良いか？
> まずいのは、グローバルIPが漏れることなのか？

## 結論

| 質問 | 答え |
|---|---|
| プライベートIPを知られても侵入にはならない？ | **外からは、その通り。** インターネットから届かないため。LANの内側に入り込まれた後は攻撃の宛先になり得るが、もともと推測しやすい値なので、知られたこと自体の影響は小さい |
| まずいのはグローバルIPが漏れること？ | **半分正解。** グローバルIPは誰からでも届くので、漏れると狙い撃ち（DDoSなど）の対象になり得る。ただし、グローバルIPは通信相手に必ず見える情報で、そもそも秘密にはできない。**漏れたら即侵入ではなく、そのIPで何が開いているかで決まる** |

大事なのは「プライベートかグローバルか」そのものより、**誰から届くか**と、**届いた先で何が開いているか**である。

## そもそもプライベートIPとグローバルIPとは

### ひとことで

| | グローバルIP | プライベートIP |
|---|---|---|
| たとえ | 建物の住所（世界に1つ） | 建物の中の部屋番号（101号室など） |
| 重複 | インターネット全体で重複しない | 家庭や会社ごとに同じ番号を使い回す |
| 割り当てる人 | ISP（契約しているプロバイダー） | 自分（ルーターのDHCPなど） |
| インターネットから届くか | 届く | 届かない |
| 例 | `203.0.113.10` | `192.168.1.10`、`10.0.0.10` |

> `203.0.113.10` は説明用の例である。`203.0.113.0/24` はドキュメントの例示用に予約された範囲（RFC 5737）。

### 家庭のネットワークで見ると

```text
              Internet（グローバルIPの世界）
                       │
                       │  203.0.113.10  ← グローバルIP（回線に1つ）
                 ┌─────┴─────┐
                 │  Router   │  ← NATで送信元のIPを書き換える
                 └─────┬─────┘
                       │  192.168.1.1
        ┌──────────────┼──────────────┐
        │              │              │
  192.168.1.10   192.168.1.11   192.168.1.12   ← プライベートIP（家の中だけ）
       PC            Phone            TV
```

- LAN内の機器はプライベートIPを持つ
- インターネットへ出るとき、ルーターが送信元を**グローバルIPに書き換える**（NAT）
- 通信相手（Webサイトなど）から見えるのは**グローバルIPだけ**

### アドレスの範囲

| 種類 | 範囲 | 定義 | 備考 |
|---|---|---|---|
| プライベートIP | `10.0.0.0/8`<br>`172.16.0.0/12`<br>`192.168.0.0/16` | RFC 1918 | インターネットでは転送されない |
| Shared Address Space | `100.64.0.0/10` | RFC 6598 | 本来はISP内部用。Tailscale IPはこの範囲を使っている |
| グローバルIP | 上記や、その他の特殊用途の範囲以外 | — | ISPから割り当てられる |

### このラボのIPを分類すると

| IP | 種類 | インターネットから届くか |
|---|---|---|
| VMのWAN：`192.168.x.x`（VMnet8） | プライベートIP | 届かない |
| VMのLAN：`10.0.0.x`（VMnet2） | プライベートIP | 届かない |
| Tailscale IP：`100.80.124.76` | Shared Address Space（プライベートでもグローバルでもない） | 届かない（tailnet内だけで使われる） |
| Windowsがつながっている回線のIP | グローバルIP（※） | 届く |

※ 回線のグローバルIPは、このリポジトリには書かれていない。

### IPv6の場合

IPv6では、**LAN内の機器にもグローバルなIPv6アドレスが付く**のが普通である。

| 種類 | 範囲 | 意味 |
|---|---|---|
| グローバルユニキャスト | `2000::/3` | インターネットで使うアドレス |
| ユニークローカル（ULA） | `fc00::/7` | IPv4のプライベートIPに近い |
| リンクローカル | `fe80::/10` | 同じリンク（同じセグメント）内だけで使う |

IPv4のようにNATで隠れないため、**ルーターのFirewallで外から始まる通信を止めることが、より重要**になる（[08 - IPv6](../../labs/08-ipv6/README.md)）。

## 回答1：プライベートIPを知られたら？

| 攻撃者がいる場所 | プライベートIPに届くか |
|---|---|
| インターネット | ✕ 届かない |
| LANの内側（感染したPC、乗っ取られたIoT機器、同じWi-Fiに入った人など） | ✓ 届く |

- **外からは、知られても侵入にはつながらない。** そもそもパケットが届かない。
- **内側に入り込まれた場合は、宛先になる。** ただし、プライベートIPは `192.168.0.1` や `192.168.1.1` のように推測しやすく、LAN内にいればスキャンですぐに分かる。そのため、**知られたこと自体の影響はほとんどない**。

守るべきなのはプライベートIPそのものではなく、**LAN内の機器を乗っ取られないこと**である。

## 回答2：グローバルIPを知られたら？

### 「漏れたら即侵入」ではない

グローバルIPを知られて起こり得ることは次の通り。

| 起こり得ること | 内容 | 影響 |
|---|---|---|
| 狙い撃ちのスキャン・攻撃 | 開いているポートや弱いパスワードを集中的に調べられる | **開いているポートが無ければ入口にならない** |
| DDoS | 回線に大量の通信を送りつけられ、インターネットが使えなくなる。配信者のIPが漏れ、配信中にDDoSを受けた事例がある | ポートを閉じていても防げない。ISP側の対策が必要 |
| おおよその地域の推定 | 国や都市のレベルで推定される | 住所や世帯までは特定できない |
| 個人との結び付け | 「このIPは〇〇さんの回線」と分かると、他の情報と組み合わせて悪用されることがある | 状況による |

侵入につながるかどうかは、**そのグローバルIPで何が開いているか**で決まる（[WANの入口は攻撃者の標的になるのか](2026-10-08-is-wan-entrance-a-target.md)）。

### そもそもグローバルIPは隠しきれない

- Webサイトを見たり、アプリを使ったりするたびに、**通信相手のサーバーにはグローバルIPが伝わる**
- インターネット全体のIPv4アドレスは、スキャナーで1時間かからずに調べ尽くせる

つまり、グローバルIPは「漏れたら危険になる秘密」ではなく、**最初から見えている前提で守るもの**である。

```text
×  グローバルIPを隠しているから安全
○  グローバルIPが見えていても、開いているポートが無く、認証が強いから安全
```

ただし、わざわざ公開する理由もない。DDoSや個人との結び付けを避けるため、**自宅回線のグローバルIPはリポジトリやSNSに書かない**のが無難である。

## 整理：プライベートIPとグローバルIPの比較

| | プライベートIP | グローバルIP |
|---|---|---|
| 届く範囲 | 同じLAN（とVPNなどでつながった場所） | インターネット全体 |
| 知られたときの影響 | ほぼない | 狙い撃ちやDDoSの対象になり得る |
| 隠せるか | 隠す必要がほぼない | 通信相手には必ず見えるので、隠しきれない |
| 本当の守り | LAN内の機器を乗っ取られないこと | 開けるポートを最小限にする・認証を強くする・更新する |

## このラボでの意味

| 段階 | WANのIP | 考えること |
|---|---|---|
| 今のラボ | プライベートIP（VMnet8） | インターネットから届かない。リポジトリに書いても問題ない |
| 将来の実機 | ISPから割り当てられるIP（多くはグローバルIP） | 知られていなくてもスキャンで見つかる。WAN側のポートを閉じる（[05 - Firewall](../../labs/05-firewall/README.md)） |

## まとめ

- **グローバルIP**は「世界に1つの住所」で、インターネットのどこからでも届く。**プライベートIP**は「家の中の部屋番号」で、LANの中でしか通じない。
- **プライベートIPを知られても、外からの侵入にはつながらない。** 守るべきは、LAN内の機器が乗っ取られないこと。
- **グローバルIPが漏れても、即侵入ではない。** ただし狙い撃ちやDDoSの対象になり得るので、わざわざ公開はしない。
- どちらの場合も、本当の守りは**届く範囲を絞ること**と**届いた先で入れないようにすること**。
